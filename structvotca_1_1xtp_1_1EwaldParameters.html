Detailed Description

The Ewald convergence parameters a background was converged with.

Written into the background's own checkpoint alongside the converged dipoles, and read back by whatever later embeds a region in that background (MM/MM, QM/MM).

The point is that these are NOT re-specified by the consuming job. A foreground embedded in a periodic background is only meaningful if it uses the same alpha, the same k-space cutoff and the same summation shape the background was converged with: alpha in particular partitions the interaction between the real- and reciprocal-space sums, so two different values do not describe the same physics at all, and the mismatch would not announce itself – both runs would converge happily to different answers. Carrying them in the checkpoint makes the inconsistency unrepresentable rather than merely discouraged.

The box is included for the same reason: the background's lattice is a property of the converged state, not something a later job should re-derive and hope matches.
