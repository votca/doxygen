Detailed Description

Kinetic Monte Carlo of several electrons or holes with site exclusion in a periodic box: drift velocity, mobility, diffusion tensor and site occupations (BulkSimulation on a bulk ToFGraph with KMCEngine).

The run length (runtime) is a simulated time in seconds if it is at most 100, otherwise a number of KMC events; outputtime is read in the same unit.
