Detailed Description

Electronic ground-state via Density-Functional Theory.

This class assembles the one- and two-electron matrix contributions needed for self-consistent Kohn-Sham calculations in a Gaussian AO basis. The SCF machinery supports restricted closed-shell calculations and unrestricted spin-polarized calculations, while reusing the same integral and numerical XC infrastructure whenever possible.

◆ ComputeAndStoreForces()

void votca::xtp::DFTEngine::ComputeAndStoreForces ( Orbitals & orb,
const Eigen::MatrixXd & Dmat,
const Vxc_Potential< Vxc_Grid > & vxcpotential ) const
private

Assemble the total ground-state nuclear gradient (one-electron [kinetic + nuclear attraction] + overlap "Pulay force" + nuclear repulsion + RI-J Coulomb + RI-K exact exchange [hybrid functionals]

  • XC, LDA or GGA) from a converged density matrix and store it in the orbital container via Orbitals::setForces(), as the physical force (-dE/dR, matching the convention external tools such as ASE expect from a Calculator's getForces()).

The overlap Pulay term, -tr(W dS/dR) with the energy-weighted density W, arises because C^T S C = I depends on the geometry through the basis functions; it is distinct from DFTGradient::PulayGradient, the basis-function term of the XC integral.

The exchange gradient uses the asymmetric V^-1 RI fit, which gives the same exchange energy as the symmetric V^-1/2 fit in ERIs::CalculateEXX_mos (exact identity for positive-definite V), so no derivative of V^-1/2 is needed.

Requires RI (auxbasis_name_ non-empty); RIJGradient/RIKGradient have no 4-centre implementation. Only called if compute_forces_ is set (<xtpdft><compute_forces>true</compute_forces></xtpdft>, default false), since it adds non-trivial cost to every SCF.

UKS (open-shell) analog of ComputeAndStoreForces; stores the force via Orbitals::setForces().

Terms: nuclear repulsion; one-electron [kinetic + nuclear attraction] and RI-J with D_total = D_alpha + D_beta; overlap Pulay with W = W_alpha + W_beta (spin densities are not pre-doubled); RI-K for hybrids as 0.5 * ScaHFX_ * [RIKGradient(C_alpha_occ) + RIKGradient(C_beta_occ)], the 0.5 because UKS exchange uses ERIs::CalculateEXX_dmat(P) = 0.5 * ERIs::CalculateEXX_mos(C) for P = C C^T; and XC (PulayGradientUKS + GridWeightGradientUKS, LDA and GGA, including the sigma_aa/sigma_ab/sigma_bb terms), checked against finite differences of IntegrateVXCSpin.

◆ Initialize()

void votca::xtp::DFTEngine::Initialize ( tools::Property & options)

Read DFT, grid, and SCF settings from the user options tree.

Self-consistent Kohn-Sham implementation.

The SCF cycle solves F C = S C eps in a Gaussian AO basis. In the restricted branch a single density matrix is iterated, whereas in the UKS branch separate alpha and beta densities are propagated while sharing the same one-electron Hamiltonian, Coulomb term, and AO overlap matrix.

Relative to the earlier restricted implementation, the UKS extension keeps the spin channels separate only where the equations require it: exchange, spin-resolved XC potentials, occupations, and convergence acceleration.

Run an unrestricted atomic reference calculation used in open-shell atomic guesses.

use_hunds_rule_occupation: if true, take the alpha/beta electron counts from a Hund's-rule ground-state table for main-group (s/p-block) elements instead of the default parity split (odd Z -> one extra alpha electron, even Z -> alpha == beta). ◆ RunCDFT()

bool votca::xtp::DFTEngine::RunCDFT ( Orbitals & orb,
HirshfeldPartition::Constraint & constraint )

Run a single, charge-constrained DFT (CDFT) calculation: finds the Lagrange multiplier lambda such that Tr[(P_alpha + P_beta) * constraint.weight_matrix] equals constraint.target_population, then converges the SCF at that lambda (Wu-Van Voorhis outer loop). Each trial SCF is warm-started from the previous trial's converged density via the "orbfile" initial guess, as in CP2K. Always uses EvaluateUKS, since a localized extra charge is usually an open-shell situation.

constraint.lambda is the initial guess for the bisection (0.0 is a reasonable default) and holds the converged value on return. Returns false if no root can be bracketed (constraints_ cleared, lambda unchanged) or if the bisection exhausts max_cdft_iterations_ without reaching cdft_population_tolerance_ (lambda set to the last bracket midpoint). Throws std::runtime_error if an inner SCF does not converge, to distinguish that from running out of outer iterations.
