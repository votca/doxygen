217 // The metric that was folded into the stored integrals at Fill time:
218 // T = Pseudo_InvSqrt_GWBSE, with T T^T = V^-1 (pseudo-inverse) and
219 // T^T V T the projector onto the retained auxiliary functions. After
220 // Fill, operator[] holds M = (mn|Q) T, so the bare Coulomb operator
221 // exists only implicitly, as M M^T.
222 //
223 // Kept because anything that must act on the Coulomb interaction in
224 // the same space as M needs it. The environment reaction field is the
225 // case in point: a kernel B between auxiliary functions, taken as charge
226 // densities, enters as M (T^T B T) M^T -- see EnvironmentScreening.
227 //
228 // IN THE FILL-TIME AUXILIARY BASIS. MultiplyRightWithAuxMatrix, which the
229 // PPM and the BSE both call with an eigenvector matrix U, rotates the
230 // auxiliary index of M. This matrix is not rotated with it: a kernel
231 // built from it has to be brought into the current frame with
232 // ToCurrentAuxFrame before it meets operator[]. Refilled, and so reset,
233 // by every Fill and Rebuild.
234 const Eigen::MatrixXd& InvSqrt() const { return inv_sqrt_; }
235
236 // The auxiliary frame operator[] is currently in. Every
237 // MultiplyRightWithAuxMatrix since the last Fill or Rebuild is recorded
238 // here, so that operator[] holds M_fill * AuxFrame() with M_fill the
239 // integrals as Fill left them. Empty means the identity: nothing has
240 // rotated them yet.
241 //
242 // The bare Coulomb interaction does not care -- it is the identity in
243 // every orthonormal frame, which is why nothing tracked this before. A
244 // kernel K between the columns of M_fill does care: M_fill K M_fill^T is
245 // M K' M^T only with K' = ToCurrentAuxFrame(K).
246 const Eigen::MatrixXd& AuxFrame() const { return aux_frame_; }
247
248 // For code that snapshots slices through operator[] and later writes
249 // them back, which bypasses the bookkeeping above: restore the frame
250 // that was current when the snapshot was taken, alongside the slices.
251 void RestoreAuxFrame(const Eigen::MatrixXd& frame) {
252 aux_frame_ = frame;
253 aux_frame_known_ = true;
254 }
255
256 // K, a kernel between the columns of M_fill, as it must be applied to
257 // operator[] now: F^-1 K F^-T with F = AuxFrame(), which is F^T K F for
258 // the orthogonal eigenvector matrices the PPM and the BSE rotate with.
259 // Throws if the frame is not known -- after a non-square
260 // MultiplyRightWithAuxMatrix, which is not a change of frame.
261 Eigen::MatrixXd ToCurrentAuxFrame(const Eigen::MatrixXd& K) const;
262
263 // Whether AuxFrame() is orthogonal, so that the bare interaction M M^T is

265 bool AuxFrameIsOrthogonal() const;
