Detailed Description

A real symmetric n x n matrix stored as the tiles of its lower triangle (about half the memory of the dense matrix).

The tiles (I, J), I >= J, are tile x tile blocks (smaller at the end), row-major, so that a row segment within a tile is contiguous. The diagonal tiles are stored in full. Rows are written with SetRowLower, which takes the columns 0..r of row r; FinishBuild() then fills the upper halves of the diagonal tiles.

Multiply(X) gives S X with the tiles of the lower triangle and their transposes, one row block of the result per task.
