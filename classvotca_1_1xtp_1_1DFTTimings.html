Detailed Description

Wall-clock accounting for the parts of a DFT run.

Entries keep the order in which they were first used, so the report reads like the run. Scopes may nest; each entry holds only its own time, without the time of scopes nested inside it, so the entries add up to the total. Scopes must be opened and closed on one thread (the serial driver code), not inside OpenMP regions.
