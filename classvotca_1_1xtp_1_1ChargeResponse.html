Detailed Description

Charge-response matrix Pi of one molecule type.

In the charge-response (CR) environment model the induced atomic charges of a molecule are dq = -Pi phi, with phi the external electrostatic potential at its atoms. Pi (N x N, atomic units e^2/Hartree) is symmetric, positive semidefinite and conserves charge (every row sums to zero). It already contains the molecule's own Coulomb screening, so induced charges of the same molecule do not interact. What charges cannot carry is in residual induced dipoles, the ordinary polarizabilities of the molecule's .mps file.

Pi is invariant under rotations, so it is stored once per molecule type in the atom order of the type's .mps file, in a .crm file:

! comment lines start with '!' N El x y z (N lines, Angstrom, the fit geometry; informational) Pi_11 ... Pi_1N (N lines of N numbers, e^2/Hartree)

written by xtp_tools -e crfit (ChargeResponseFit) or the PySCF script xtp_cr_fit: the response to Hirshfeld-localized potentials, measured with Hirshfeld charges.
