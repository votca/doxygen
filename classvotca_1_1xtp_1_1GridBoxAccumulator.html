Detailed Description

Adds per-grid-box blocks into a set of AO matrices from inside an OpenMP loop over grid boxes.

A single critical section around all matrices serializes the loop when there are many of them (one per response density or per atom). Two strategies instead:

  • thread-local copies of all target matrices, summed once in Finish(), when they fit into the memory budget (no synchronization at all);
  • otherwise one lock per matrix, taken in a thread-dependent order so that threads work on different matrices. Results are identical up to the order of floating-point additions.

Usage: construct before the parallel loop, call Add() inside it (any thread), call Finish() after it.
