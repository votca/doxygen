◆ LinearisedRoot()

boost::optional< double > votca::xtp::qp_solver::LinearisedRoot ( double w0,
double f0,
double fprime )
inline

One Newton step of the QP equation f(w) = 0 from w0, with f0 = f(w0) and fprime = f'(w0) = dSigma_c/dw - 1: w0 - f0 / fprime = w0 + Z f0, with the quasiparticle weight Z = 1 / (1 - dSigma_c/dw). None if f' vanishes.

◆ RootBracketTolerance()

double votca::xtp::qp_solver::RootBracketTolerance ( const SolverOptions & opt)
inline

Bracket width at which the interval refinement stops if |f| has not yet dropped below g_sc_limit. Roots are accepted only with |f| <= g_sc_limit (AcceptRoot), and |f'| = 1/Z <= 1/min_accepted_Z near a root, so a root located to within this width has an acceptable residual even for the smallest accepted weight: the refinement does not throw away roots by stopping early.

◆ SolveQP_Tracked()

template<typename QPFunc>
boost::optional< RootCandidate > votca::xtp::qp_solver::SolveQP_Tracked ( QPFunc & fqp,
double center,
double halfwidth,
double Z_previous,
double min_Z_fraction,
const SolverOptions & opt,
bool use_brent = false )

Root tracking: the root of the branch found in the previous iteration, searched only in [center - halfwidth, center + halfwidth] with the dense spacing. Returns the accepted root closest to center whose weight is at least min_Z_fraction of the previous one (the branch has not faded into a satellite); none if there is no such root, so that the caller falls back to the full search.
