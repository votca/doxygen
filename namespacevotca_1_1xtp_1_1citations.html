Detailed Description

References for the methods used in a run.

The code that runs a method calls Cite with the key of its reference (the keys of the bibliography of the manual). The application prints the references used, in the order of first use, at the end of the run. The table of calculators gives the references every run of a calculator uses and those that depend on its options (printed by –cite).
